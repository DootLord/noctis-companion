# Local rules data

`wizard-spells-2014.json` is the app's local Wizard spell catalogue. It contains the 2014 Player's Handbook Wizard spells plus Wizard spells from the user-supplied **Ryoko's Guide to the Yokai Realms v0.90**. Each entry has a `sourceShort` field so the UI can distinguish sources.

`feats-2014.json` contains the 2014 Player's Handbook feats plus the general and racial feats from Ryoko v0.90. Racial feats remain visible for reference but are locked when the character does not meet their racial prerequisite.

Text is normalised for practical table use rather than preserved as a literal OCR transcription.
